# JPU_Blanck_Project

Exercice de cours Java servant de base au jeu Insane Vehicles : squelette du modèle, de la vue et
du contrôleur, et éléments mobiles à compléter.

## Contenu

- `src/fr/exia/insanevehicles/` : classes de base, route, sprite, éléments et véhicule
- `road.txt` : carte lue au démarrage
- `images/` : ressources graphiques

## Stack

Java, Swing.

## Lancer le projet

Importer le projet dans Eclipse et exécuter `InsaneVehicles.java`.

## Contexte

Exercice d'école (2020). Les versions complétées se trouvent dans `JPU_Prosit_4` et
`JPU_Prosit5`.
